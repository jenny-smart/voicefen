# 魏世芬聲音教練｜課程收費對帳系統

## 系統架構

```
前台網頁（學員）              後台管理（老師）
  GAS doGet()          ←→     Streamlit app.py
  Index.html                   發送 POST 給 GAS
       ↓  ↑
  Google Apps Script (Code.gs)
       ↓  ↑
  Google Sheets
  ├── 課程主檔
  ├── 訂單主檔
  └── 付款明細
```

---

## 部署步驟

### 第一步：建立 Google Sheets

1. 開啟 Google Sheets，新增試算表
2. 命名為「魏世芬聲音教練 收費系統」
3. 記下試算表的 ID（網址列中的長串字元）

### 第二步：部署 Google Apps Script

1. 在試算表選單：**擴充功能 → Apps Script**
2. 將 `gas/Code.gs` 內容貼入 `Code.gs`
3. 新增 HTML 檔案 `Index`，將 `gas/Index.html` 內容貼入
4. 設定 Script 屬性：
   - 選單：**專案設定 → 指令碼屬性**
   - 新增：`ADMIN_TOKEN` = 你設定的密碼（英數字，例如：`vf2025admin`）
5. 執行 `initSheets()` 函式初始化試算表結構
6. 部署為網頁應用程式：
   - **部署 → 新增部署作業**
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 存取權限：**所有人**
   - 複製部署網址（前台學員就用這個網址）

### 第三步：部署 Streamlit 後台

1. 將 `streamlit/` 資料夾推送到 GitHub repo
2. 至 [share.streamlit.io](https://share.streamlit.io) 部署
3. 在 **Settings → Secrets** 填入：

```toml
GAS_URL     = "https://script.google.com/macros/s/你的部署ID/exec"
ADMIN_TOKEN = "vf2025admin"   # 與 GAS 設定的要一致
```

4. 完成！後台網址分享給世芬老師使用

## 功能說明

### 前台（學員端）
| 功能 | 說明 |
|------|------|
| 課程介紹 | 動態載入後台設定的課程，含名稱/說明/金額 |
| 課程報名 | 填寫姓名/手機/課程，送出後產生訂單編號 |
| 查詢訂單 | 輸入手機號碼查詢所有報名記錄 |
| 補填付款 | 付款後填寫方式/帳號後5碼/金額 |

### 後台（管理端 Streamlit）
| 頁面 | 功能 |
|------|------|
| 收費總覽 | KPI 數字、月趨勢圖、待收款清單、課程分布 |
| 訂單管理 | 篩選/搜尋訂單、手動更新狀態 |
| 對帳核對 | 逐筆確認付款、標記已核對/異常 |
| 課程設定 | 新增/編輯/停用課程（前台即時更新） |
| 匯出報表 | 下載訂單/付款/月統計 CSV |

## Google Sheets 欄位說明

### 課程主檔
`課程ID | 課程名稱 | 課程類型 | 課程說明 | 圖示 | 單價 | 計費單位 | 是否開放 | 精選標記 | 建立時間`

### 訂單主檔
`訂單編號 | 報名時間 | 姓名 | 手機 | Email | 課程ID | 課程名稱 | 應付金額 | 備註 | 訂單狀態 | 最後更新`

### 付款明細
`付款ID | 訂單編號 | 付款時間 | 付款方式 | 帳號後5碼 | 實付金額 | 備註 | 核對狀態 | 核對時間 | 核對備註`

## 訂單狀態流程

```
[報名送出]
    ↓
待付款  →（學員補填付款資料）→  待對帳  →（老師核對）→  已付款
         →（老師手動更新）────────────────────────────→  已付款
```
